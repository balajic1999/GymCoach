## Mixamo License Summary

Per Adobe Mixamo Terms of Service:
- Characters and animations downloaded from Mixamo are free to use for commercial purposes
- No attribution required
- Can be modified and incorporated into projects
- Cannot be resold as standalone 3D assets

## License Review Process

Before any 3D asset is added to the project:

1. Document the source and license type
2. Verify commercial use is permitted
3. Document any attribution requirements
4. Save license proof (screenshot/link) in `assets/licenses/`
5. Update this document
6. Get approval if license terms are unclear
